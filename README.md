# Target promo code: how to stack Circle offers, one checkout code and cashback without voiding any of it

Most people searching for a Target promo code want one thing: a box to paste something into that makes the total drop. That box exists. It also does less than the coupon pages imply, and the way most shoppers use it quietly cancels out a second discount they didn't know they had.

Here's what actually works at Target, in the order the discounts apply, plus the thing almost no promo code list mentions: the cashback layer that keeps paying after you've closed the tab.

## The promo code field at Target, and its one hard limit

On target.com, the code field sits under "Potential savings" above the Order Summary. In the Target app it's labelled "Add promo code" in roughly the same spot. Paste, hit Apply or Redeem, and the discount shows up in the summary before you pay. Nothing exotic.

The limit is what catches people: **Target generally allows one promo code per order** [2][3]. Not one per item, one per order. So if you've got two codes sitting in a notes app, you're choosing between them, not adding them together.

Where the flexibility does exist is stacking *different types* of discounts on the same item. Target allows one manufacturer coupon, one broad category offer (say, a Circle deal for "20% off clothing"), and one item-level offer on a single product [1]. Three layers, three different sources. Two manufacturer coupons on the same item, no.

One more timing detail worth knowing: Circle offers refresh on Sundays, typically between midnight and 2 a.m. central time. If Friday's offers look thin, waiting until Sunday morning is a real strategy, not superstition [4].

## Why so many "Target promo code" lists disappoint

Open a coupon aggregator page for Target and you'll find headlines like "25% off" sitting next to a code that turns out to be category-locked, first-order-only, or expired [2][3]. One aggregator's own Target page reported it had one active code at the time of its listing [3]. That's the honest picture: Target promo codes are seasonal and narrow, not a permanent sitewide lever.

Target's bigger, more reliable discounts mostly aren't codes at all:

- **Target Circle** is free to join and is where most standing offers live — category discounts, item-level deals, gift card promotions, personalized bonuses [1][4].
- **The Target Circle Card** (the card formerly called the REDcard) takes 5% off most eligible purchases, and it applies after other discounts [1][5].
- **Free shipping** kicks in on orders of $35 or more, or on any order paid with a Circle Card [1].
- **Registry completion coupons** (baby or wedding) have been listed at 15% off remaining registry items, and coupon trackers list a 15% student discount that requires verifying enrollment in your account settings [5].

None of these require hunting for a code that may have died last Tuesday. That's the part coupon pages bury.
